# LINKAVTO — обзор проекта

> Материал для написания поста в Telegram. Ниже — что это за проект, какой стек,
> какие функции реализованы и как всё устроено. Можно брать любые куски.

## Что это

**LINKAVTO** — маркетплейс автозапчастей (по типу Exist / Emex / Autodoc). Фронтенд-витрина
интернет-магазина, где пользователь подбирает запчасти под свой автомобиль, сравнивает
предложения разных продавцов и оформляет заказ.

Это **clean-room редизайн**: старый сайт был на Django, а сейчас пишется современный
самостоятельный фронтенд по новому техническому заданию (не пиксельная копия старого,
а переосмысленный дизайн и UX). Витрина уже полностью работает на моках API —
то есть кликабельна и наполнена данными, ещё до готовности реального бэкенда.

## Технологический стек

Современный «bleeding-edge» фронтенд 2025 года:

- **React 19** + **TypeScript 5.7** — строгая типизация, `tsc --noEmit` проходит чисто
- **Vite 6** — сборщик и dev-сервер
- **React Router 7** — data-router, все страницы через lazy-загрузку (code splitting)
- **TanStack Query 5** — серверное состояние, кеширование запросов, пагинация
- **Zustand 5** — клиентское состояние (корзина, избранное, гараж, авторизация)
- **Tailwind CSS 4** — стилизация через `@theme`-токены (новый движок `@tailwindcss/vite`)
- **React Hook Form + Zod 4** — формы и валидация
- **ky** — HTTP-клиент поверх fetch
- **MSW 2** (Mock Service Worker) — моки API прямо в браузере
- **motion (Framer Motion) + GSAP + Lenis** — анимации, плавный скролл, scroll-driven эффекты
- **lucide-react** — иконки

**Архитектура — Feature-Sliced Design (FSD):** код разбит по слоям
`app / shared / entities / features / pages`. Алиас `@` → `src`. Деньги везде хранятся
в **целых копейках** (без float-ошибок).

## Ключевые функции (фичи)

### 🔎 Умный поиск
Единая строка поиска, которая **сама распознаёт тип запроса**: VIN-номер, артикул (SKU) или
обычный текст. Есть автоподсказки (suggest), история запросов.

### 🚗 Гараж и подбор по автомобилю (fitment)
- Пользователь добавляет свои машины в «Гараж» (марка → модель → модификация → год, VIN).
- Каскадный подбор автозапчастей: **класс техники → марка → модель → поколение → модификация**.
- **Контекстная полоса «Гараж»** над каталогом: показывает «Смотрим для {ваше авто}»
  и умеет фильтровать «только подходящие детали». Совместимые товары получают бейдж
  «Подходит вашему авто».
- Контекст авто протягивается сквозь навигацию через URL-параметр.

### 🧩 Умные фильтры каталога (facet-driven)
Набор фильтров **зависит от раздела**: для шин и дисков появляются свои фасеты
(диаметр, ширина, сезонность, PCD, вылет), для масел/химии — динамические атрибуты
(вязкость, объём и т.п.), везде — производитель, бренд, цена. Есть **гистограмма цен**
со слайдером диапазона. Каскад подбора авто адаптируется под раздел
(в «Грузовых» — только грузовая техника и т.д.).

### 🛒 Корзина и оформление заказа
- Корзина сгруппирована **по продавцам** (каждый со своей суммой и доставкой).
- Оформление: адрес, способ доставки (СДЭК / Почта / самовывоз), способ оплаты.
- Гостевая корзина/гараж **сливаются** с аккаунтом после входа (merge guest state).

### 👤 Авторизация и профиль
- Вход по **e-mail с кодом** (без паролей).
- Личный кабинет: заказы и их статусы, детали заказа, адреса, настройки.

### 🏪 Продавцы и товары
- Карточка товара: галерея, характеристики, OEM-номер, **кросс-номера (аналоги)**,
  совместимость, «паспорт детали».
- **Таблица предложений** от разных продавцов (цена, срок поставки, наличие, оригинал/аналог).
- Отзывы и рейтинги, форма отзыва.
- Страница продавца, страница «Стать продавцом».
- Избранное, шеринг товара.

### 🏠 Витрина
Главная страница с промо-баннерами (карусель), подборками товаров, меню каталога.
Статические страницы (о доставке, оплате и т.п.).

## Дизайн-система

Строгая и цельная: **светлая тема, монохром + ОДИН синий акцент** (`#2f6be5`), без
цветового кодирования категорий. Все дизайн-токены (цвета, типографика, отступы, радиусы,
тени, анимации) живут **только** в одном файле `src/styles/index.css` через `@theme` —
ни одного hex-цвета или px-размера в компонентах.

- Шрифты: **Golos Text** (текст), **Unbounded** (логотип), **IBM Plex Mono** (моно).
- Акцент на движении: fade-up при въезде секций во вьюпорт, пружинящий счётчик корзины,
  scroll-driven эффекты (блок «заливает экран» скруглением при скролле). Уважается
  `prefers-reduced-motion`.
- Внимание к доступности: контроль контраста (WCAG), фокус-состояния, зоны нажатия.

## Как это работает без бэкенда

Витрина запущена на **MSW-моках**: сервис-воркер перехватывает запросы к `/api/v1/`
и отдаёт реалистичные данные. Полностью замокан весь API-контракт (~30 эндпоинтов):
категории и дерево каталога, каскад подбора авто, товары с предложениями/похожими/отзывами,
поиск с подсказками, авторизация, корзина, гараж, баннеры, подборки главной, заказы, продавцы.

Когда появится реальный Django-бэкенд на `/api/v1/`, фронт переключается на него без
переписывания — типы контракта уже описаны (позже сгенерируются из OpenAPI-схемы).

## Масштаб проекта

- ~14 полноценных страниц, все типизированы и кликабельны.
- ~100 файлов исходников, аккуратно разложенных по FSD-слоям.
- Русскоязычный интерфейс (i18n-словарь).
