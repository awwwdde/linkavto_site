О структуре каталога

Каталог товаров имеет 3-уровневую иерархию:

  • Уровень 1: Корневые категории (Легковые автомобили, Грузовики и т.д.)
  • Уровень 2: Подкатегории (Двигатель, Трансмиссия и т.д.)
  • Уровень 3: Под-подкатегории (ГРМ, Поршневая группа и т.д.)

Все категории управляются через Django админ-панель в модели Category.

🎯 Часть 1: Работа с категориями

1.1. Доступ к админ-панели

1 Откройте админ-панель
https://ваш-домен.ru/admin/

Введите логин и пароль суперпользователя.

2 Перейдите в раздел категорий

В левой панели найдите секцию "SHOP" → кликните на "Категории (Categories)"

Shop → Categories

1.2. Создание корневой категории (Уровень 1)

📌 Важно: Корневых категорий должно быть ровно 10, они определены в коде и отображаются в меню.
1 Нажмите кнопку "Добавить категорию" (Add Category)

В правом верхнем углу списка категорий.

2 Заполните обязательные поля
Название (Name):
Введите название категории, например: Легковые автомобили
Slug:
Автоматически генерируется из названия. Используется в URL.
Например: legkovye-avtomobili
Родительская категория (Parent):
Оставьте пустым! Это корневая категория.
Показывать в (Show in):
Самое важное поле! Выберите соответствующее значение из списка:
Значение Описание
cars Легковые автомобили
trucks Грузовики
moto Мототехника
special Спецтехника
accessories Аксессуары
chemistry Автохимия и масла
tools Инструменты
tires Шины и диски
electrics Автоэлектрика
dlya-to Для ТО
Активность (Is active):
Поставьте галочку ✓ — категория будет видна на сайте
3 Загрузите изображение (опционально)

Раскройте секцию "Дополнительно"

Изображение (Image):
Нажмите "Выбрать файл" и загрузите изображение категории.
Рекомендации:
  • Размер: минимум 300x300px
  • Формат: PNG, JPG
  • Вес: до 1 МБ
💡 Совет: Если не загрузить изображение, на сайте отобразится градиентный фон синего цвета с названием категории.
4 Сохраните категорию

Внизу страницы нажмите "Сохранить" или "Сохранить и добавить другой объект"

1.3. Создание подкатегории (Уровень 2)

Пример:
Создадим подкатегорию "Двигатель" для категории "Легковые автомобили"
1 Нажмите "Добавить категорию"
2 Заполните поля
Название (Name):
Двигатель
Slug:
dvigatel (генерируется автоматически)
Родительская категория (Parent):
ВЫБЕРИТЕ корневую категорию!
В выпадающем списке найдите и выберите: Легковые автомобили
Показывать в (Show in):
Оставьте пустым! Это поле нужно только для корневых категорий.
Активность (Is active):
Поставьте галочку ✓
3 Сохраните
⚠️ Внимание: Убедитесь, что вы выбрали правильную родительскую категорию! От этого зависит, где будет отображаться подкатегория в меню.

1.4. Создание под-подкатегории (Уровень 3)

Пример:
Создадим под-подкатегорию "ГРМ" для подкатегории "Двигатель"
1 Нажмите "Добавить категорию"
2 Заполните поля
Название (Name):
ГРМ
Slug:
grm
Родительская категория (Parent):
ВЫБЕРИТЕ подкатегорию!
В выпадающем списке найдите и выберите: Двигатель
(Будет отображаться как Легковые автомобили → Двигатель)
Показывать в (Show in):
Оставьте пустым!
Активность (Is active):
Поставьте галочку ✓
3 Сохраните

📦 Часть 2: Работа с товарами

2.1. Создание товара

1 Перейдите в раздел товаров
Shop → Товары (Products)

Нажмите "Добавить товар" (Add Product)

2 Заполните основную информацию
Название (Name):
Например: Ремень ГРМ Gates 5521XS
Артикул (SKU):
Уникальный артикул товара: 5521XS
Описание (Description):
Подробное описание товара, характеристики, применимость
Цена (Price):
Например: 2500.00
Количество на складе (Stock):
Например: 15
3 Привяжите товар к категории
Категория (Category):
ВЫБЕРИТЕ САМУЮ НИЖНЮЮ (3-ю) КАТЕГОРИЮ!

В выпадающем списке найдите нужную под-подкатегорию:
ГРМ
(Отображается как Легковые автомобили → Двигатель → ГРМ)
⚠️ Важно:
• Товар нужно привязывать именно к под-подкатегории (3-й уровень)
• Не привязывайте товары к корневым категориям или подкатегориям
• Один товар может быть в нескольких под-подкатегориях
💡 Как понять, что выбрана правильная категория?
В названии категории должно быть 3 части через стрелку (→):
Корневая → Подкатегория → Под-подкатегория
4 Привяжите товар к бренду
Бренд автомобиля (Car Brand):
Выберите бренд из списка: Volkswagen, Toyota и т.д.
Это для легковых автомобилей.
Производитель (Manufacturer):
Производитель запчасти: Gates, Bosch и т.д.
💡 Для разных типов техники:
• Легковые автомобили → Car Brand
• Грузовики → Truck Brand
• Мототехника → Moto Brand
• Спецтехника → Special Brand
5 Добавьте изображение товара
Изображение (Image):
Загрузите основное фото товара
Рекомендации:
  • Размер: минимум 600x600px
  • Формат: PNG, JPG
  • Белый фон предпочтительнее
6 Укажите VIN-номер (если есть)
VIN-номер (VIN Number):
Для оригинальных запчастей: WVWZZZ1KZAW123456
Для некоторых аналогов VIN также может быть указан
7 Установите флаги товара (опционально)
Доступен (Is Available): ✓ — товар в наличии
Новинка (Is New): ✓ — отобразится бейдж "Новинка"
Рекомендуемый (Is Featured): ✓ — попадет в раздел рекомендуемых
Оригинал (Is Original): ✓ — оригинальная запчасть
8 Сохраните товар

Нажмите "Сохранить" внизу страницы

🔍 Часть 3: Проверка и управление

3.1. Как проверить иерархию категорий

1 В списке категорий

В админ-панели в списке категорий обратите внимание на колонку "Родительская категория"

  • Корневые категории: Parent = (пусто)
  • Подкатегории: Parent = Легковые автомобили
  • Под-подкатегории: Parent = Двигатель
2 На фронтенде сайта

Откройте сайт и нажмите кнопку "Каталог" в шапке

  • Десктоп: Слева корневые категории, справа сетка подкатегорий с под-подкатегориями
  • Мобильная версия: Карточки корневых категорий (3 в ряд)

3.2. Редактирование категорий и товаров

В списке категорий/товаров просто кликните на нужную запись для редактирования

Измените нужные поля и нажмите "Сохранить"

3.3. Удаление категорий

⚠️ Осторожно! При удалении родительской категории удаляются все её дочерние категории и товары!

Выделите нужные категории галочками слева

В выпадающем списке "Действие" выберите "Удалить выбранные объекты"

Нажмите "Выполнить"

Подтвердите удаление

📊 Часть 4: Полезные команды Django

4.1. Создание тестовых данных через консоль

Создание корневых категорий
python manage.py create_root_categories

Создает все 10 корневых категорий автоматически

Создание подкатегорий
python manage.py create_car_truck_subcategories

Создает подкатегории для легковых автомобилей и грузовиков

Создание под-подкатегорий
python manage.py create_subsubcategories

Создает под-подкатегории для существующих подкатегорий

Создание тестовых товаров
python manage.py create_test_products

Создает ~300 тестовых товаров с правильной привязкой к категориям

Добавление VIN-номеров
python manage.py add_vin_to_products

Добавляет VIN-номера к существующим товарам

❓ Часть 5: Частые вопросы

Q: Почему категория не отображается в меню?

A: Проверьте:

  • Стоит ли галочка Is Active
  • Правильно ли заполнено поле Show in (для корневых категорий)
  • Правильно ли выбрана Parent категория (для подкатегорий)

Q: Товар не отображается в категории

A: Убедитесь:

  • Товар привязан именно к под-подкатегории (3-й уровень)
  • У товара стоит галочка Is Available
  • Категория товара активна (Is Active)

Q: Как добавить новую корневую категорию?

A: Корневые категории жестко заданы в коде (10 штук). Чтобы добавить новую:

  1. Откройте файл shop/models.py
  2. Найдите SHOW_IN_CHOICES в модели Category
  3. Добавьте новую пару ('код', 'Название')
  4. Сделайте миграции: python manage.py makemigrations
  5. Примените: python manage.py migrate

Q: Как массово добавить товары?

A: Есть несколько способов:

  • Использовать Django админку с функцией импорта (если установлен django-import-export)
  • Написать свою management команду по аналогии с create_test_products
  • Использовать API (если реализовано)
