# 🗄️ Структура базы данных LinkAvto

## 📋 Обзор системы

Проект LinkAvto - это интернет-магазин автозапчастей с сложной системой категоризации и совместимости товаров с различными типами транспорта.

## 🏗️ Основные компоненты

### 1. 👤 Пользователи и аккаунты (`accounts/`)

#### `User` (стандартная модель Django)
- Базовые данные пользователя
- Аутентификация и авторизация

#### `Profile`
- Расширенный профиль пользователя
- `phone` - телефон (уникальный)
- `city` - город
- `photo` - фото профиля
- Связь: `OneToOne` с `User`

#### `Address`
- Адреса доставки пользователей
- `user` - владелец адреса
- `title` - название адреса
- `full_address` - полный адрес
- `is_default` - адрес по умолчанию
- `comment` - комментарий

#### `VerificationCode`
- Коды верификации для входа
- `login` - email или телефон
- `code` - 6-значный код
- `is_used` - использован ли код
- `attempts` - количество попыток

### 2. 🛍️ Товары и категории (`shop/`)

#### 🏷️ Система категорий

##### `Category` - Основная иерархическая система
```python
# Структура:
# Корневая категория (parent=None)
#   └── Подкатегория (parent=корневая)
#       └── Подподкатегория (parent=подкатегория)
```

**Поля:**
- `name` - название категории
- `slug` - URL-слаг (уникальный)
- `parent` - родительская категория (self-reference)
- `show_in` - в каком разделе показывать:
  - `cars` - легковые автомобили
  - `trucks` - грузовики
  - `moto` - мототехника
  - `special` - спецтехника
  - `accessories` - аксессуары
  - `chemistry` - автохимия и масла
  - `tools` - инструменты
  - `tires` - шины и диски
  - `electrics` - автоэлектрика
  - `dlya-to` - для ТО
- `icon` - иконка Bootstrap
- `image` - изображение категории
- `is_active` - активна ли категория
- `order` - порядок сортировки

##### Специализированные категории

**`OilAndChemistryCategory`** - Автохимия и масла
- Связана с `Category` через `parent`
- Используется для масел, жидкостей, химии

**`MaintenanceCategory`** - Техническое обслуживание
- Фильтры, свечи, ремни, расходники

**`TireAndWheelCategory`** - Шины и диски
- Летние/зимние шины, литые/штампованные диски

**`ToolCategory`** - Инструменты
- Наборы инструментов, ключи, головки

**`AutoElectricCategory`** - Автоэлектрика
- Фары, лампы, проводка, разъемы

**`AccessoryCategory`** - Аксессуары
- Чехлы, коврики, аудио, освещение

#### 🚗 Система брендов и моделей

##### Бренды транспорта
- **`CarBrand`** - легковые авто (Audi, BMW, Mercedes...)
- **`TruckBrand`** - грузовики (КамАЗ, ГАЗ...)
- **`MotoBrand`** - мототехника (Yamaha, Kawasaki...)
- **`SpecialBrand`** - спецтехника (Caterpillar, Hitachi...)

**Общие поля:**
- `name` - название бренда
- `slug` - URL-слаг
- `logo` - логотип
- `country` - страна
- `year_founded` - год основания
- `is_active` - активен ли бренд

##### Типы транспорта
- **`CarType`** - типы кузова (седан, хэтчбек...)
- **`TruckType`** - типы грузовой техники
- **`MotoType`** - типы мототехники
- **`SpecialType`** - типы спецтехники

##### Модели и поколения
- **`CarModel`** - модели легковых авто
- **`TruckModel`** - модели грузовиков
- **`MotoModel`** - модели мототехники
- **`SpecialModel`** - модели спецтехники

- **`CarGeneration`** - поколения моделей
- **`TruckGeneration`** - поколения грузовиков
- **`MotoGeneration`** - поколения мототехники
- **`SpecialGeneration`** - поколения спецтехники

**Связи:**
- Модель → Бренд (ForeignKey)
- Модель → Тип (ForeignKey)
- Поколение → Модель (ForeignKey)

#### 🛍️ Товары

##### `Product` - Основная модель товаров

**Основная информация:**
- `name` - название товара
- `slug` - URL-слаг (уникальный)
- `part_number` - артикул (уникальный)
- `description` - описание
- `short_description` - краткое описание
- `image` - основное изображение

**Цена и наличие:**
- `price` - цена
- `old_price` - старая цена (для скидок)
- `stock` - остаток на складе
- `is_original` - оригинал ли товар
- `is_active` - активен ли товар
- `is_featured` - рекомендуемый
- `is_new` - новинка

**Категории и производители:**
- `category` - основная категория (обязательно)
- `manufacturer` - производитель запчасти

**Специализированные категории:**
- `oil_chem_category` - категория автохимии
- `oil_chem_brand` - бренд автохимии
- `maintenance_category` - категория ТО
- `maintenance_brand` - бренд ТО
- `tire_wheel_category` - категория шин
- `tire_wheel_brand` - бренд шин
- `tool_category` - категория инструментов
- `tool_brand` - бренд инструментов
- `auto_electric_category` - категория автоэлектрики
- `auto_electric_brand` - бренд автоэлектрики

**Совместимость с транспортом:**
- `vehicle_type` - тип транспорта (car, truck, moto, special, universal)
- `vin` - VIN-код оригинальной запчасти

**Связи с брендами и моделями:**
- `car_brand` - бренд легкового авто
- `car_models` - модели легковых авто (ManyToMany)
- `car_generations` - поколения легковых авто (ManyToMany)
- `truck_brand` - бренд грузовика
- `truck_models` - модели грузовиков (ManyToMany)
- `truck_generations` - поколения грузовиков (ManyToMany)
- `moto_brand` - бренд мото
- `moto_models` - модели мото (ManyToMany)
- `moto_generations` - поколения мото (ManyToMany)
- `special_brand` - бренд спецтехники
- `special_models` - модели спецтехники (ManyToMany)
- `special_generations` - поколения спецтехники (ManyToMany)

**Технические характеристики:**
- `weight` - вес (кг)
- `dimensions` - габариты
- `warranty` - гарантия (месяцы)

**Специализированные поля:**
- `viscosity` - вязкость масла (5W-30, 5W-40...)
- `volume` - объем (литры)
- `filter_type` - тип фильтра
- `spark_plug_type` - тип свечи
- `maintenance_type` - тип расходника ТО

##### Дополнительные модели товаров

**`ProductImage`** - Дополнительные изображения
- `product` - товар
- `image` - изображение
- `order` - порядок отображения
- `alt_text` - альтернативный текст

**`ProductAttribute`** - Атрибуты для фильтрации
- `name` - название атрибута
- `slug` - URL-слаг
- `is_filter` - использовать в фильтрации
- `order` - порядок сортировки

**`ProductAttributeValue`** - Значения атрибутов
- `attribute` - атрибут
- `value` - значение
- `slug` - URL-слаг
- `products` - товары (ManyToMany через `ProductAttributeThrough`)

**`PartSubcategory`** - Подкатегории запчастей
- `name` - название
- `slug` - URL-слаг
- `parent_category` - основная категория

## 🔗 Ключевые связи и логика

### 1. Иерархия категорий
```
Category (корневая)
  └── Category (подкатегория)
      └── Category (подподкатегория)
```

### 2. Связи товаров
```
Product
├── category (основная категория) → Category
├── manufacturer (производитель) → Manufacturer
├── car_brand (бренд авто) → CarBrand
├── car_models (модели) → CarModel (ManyToMany)
├── oil_chem_category (категория масел) → OilAndChemistryCategory
└── oil_chem_brand (бренд масел) → OilAndChemistryBrand
```

### 3. Система совместимости
- **VIN-коды** - для точного определения совместимости
- **Бренд + Модель + Поколение** - для фильтрации по автомобилю
- **Тип транспорта** - для разделения по видам техники

### 4. Специализированные товары
- **Масла** - используют `OilAndChemistryCategory` и `OilAndChemistryBrand`
- **Инструменты** - используют `ToolCategory` и `ToolBrand`
- **Шины** - используют `TireAndWheelCategory` и `TireAndWheelBrand`
- **Автоэлектрика** - используют `AutoElectricCategory` и `AutoElectricBrand`

## 🎯 Рекомендации по использованию

### Для создания товаров:
1. Выберите основную `Category` (обязательно)
2. Выберите `Manufacturer` (производитель запчасти)
3. Если товар для конкретного авто - укажите `car_brand`, `car_models`
4. Если это масло - укажите `oil_chem_category` и `oil_chem_brand`
5. Заполните специализированные поля (viscosity, volume и т.д.)

### Для фильтрации:
1. По категории - используйте `category`
2. По бренду авто - используйте `car_brand`
3. По модели - используйте `car_models`
4. По VIN - используйте `vin`
5. По типу товара - используйте `product_type`

### Для админки:
- Основные товары редактируются через стандартную админку
- Специализированные товары имеют дополнительные поля
- Используйте фильтры по `product_type` для группировки
